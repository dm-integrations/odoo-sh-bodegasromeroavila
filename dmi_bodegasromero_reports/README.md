## Descripción

Este módulo **[Nombre del Módulo]** proporciona la siguiente funcionalidad:
- Añadimos personalizaciones para los informes
- ...


## Requisitos

- Odoo versión 17
- Otros módulos dependientes, si los hay:
  - `base` 
  - `web`

## Instalación

Instalación del módulo en el sistema.


## Configuración

Añadir en los ajustes > Configurar diseño del documento. dentro del campo términos y condiciones el texo a mostrar en el pie de pagina.
